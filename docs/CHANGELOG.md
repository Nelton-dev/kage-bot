# Kage-Bot: Histórico de alterações

Este ficheiro regista as alterações importantes ao projeto.

## Estado inicial da documentação

### Funcionalidades conhecidas

- Ligação ao WhatsApp com Baileys.
- Comando ping.
- Menu de comandos.
- Pesquisa de animes através da AniList.
- Tradução opcional das descrições.
- Consulta de animes da temporada.
- Ranking de animes.
- Recomendação aleatória de animes.

### Próximas melhorias

- Confirmar todos os comandos no ambiente real.
- Consolidar o menu e o carregamento dos módulos.
- Implementar pesquisa de filmes e séries.
- Melhorar a documentação técnica.

## Como registar uma alteração

Para cada mudança importante, acrescentar:

- Data.
- Funcionalidade alterada.
- Ficheiros modificados.
- Testes realizados.
- Problemas conhecidos.

Não registar como concluída uma funcionalidade que ainda não foi testada.
